# Portfolyo

Yazılım geliştirme eğitimim kapsamında ASP.NET Core MVC ile geliştirilmiş bir portfolyo web uygulaması.

## Teknolojiler

- ASP.NET Core MVC
- C#
- HTML
- CSS
- Bootstrap

## Amaç

Bu proje, ASP.NET Core MVC mimarisi ve web geliştirme temelleri üzerine pratik yapmak amacıyla oluşturulmuştur.
